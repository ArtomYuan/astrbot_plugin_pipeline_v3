# astrbot_plugin_pipeline

AstrBot 多角色路由演出插件：单 Bot 私聊场景下，多个角色人格轮流响应（按需触发/静默/旁白）。

## 功能

- **多角色轮流**：消息进来后轮流询问每个角色人格「这条消息是否在叫你」——被点名的角色以自身人格回应
- **按需触发**：直接叫谁谁回应；群体称呼（你们/大家）全员回应；无关消息完全静默
- **旁白叙事**：场景/动作/环境描述由旁白人格输出叙事
- **上下文感知**：近期台词注入判断——角色是否在场影响群体称呼的指代
- **人格复用**：直接使用 AstrBot 人格系统（persona_manager）——不复制人设，人格固化不受影响
- **状态持久化**：台词历史/关系状态存于 AstrBot data 目录（插件重装不丢失）

## 安装

1. 将插件目录放入 AstrBot 插件目录（`<AstrBot>/data/plugins/astrbot_plugin_pipeline/`）
2. 在 AstrBot WebUI 插件管理中重载/启用插件
3. 插件设置中配置 `persona_ids`（参与演出的角色人格 ID 列表）

## 配置（WebUI 插件设置）

| 配置项 | 说明 | 默认 |
|:--|:--|:--|
| `persona_ids` | 参与演出的角色人格 ID，逗号分隔 | 空（使用内置默认） |
| `judge_provider_id` | 判断层模型（AstrBot provider ID） | `deepseek_talk/deepseek-v4-flash` |
| `judge_temperature` | 判断层温度（越低越确定） | `0` |
| `judge_no_reasoning` | 判断层关闭思考链（更快） | `true` |

**角色人格要求**：角色人格在 AstrBot 人格管理中创建；「旁白」人格用于场景叙事（可选但建议保留）。

## 使用

- 直接称呼角色 → 该角色回应
- 群体称呼（你们/大家/都在吗）→ 所有角色回应
- 场景/动作描述 → 旁白叙事
- 无关内容 → 静默

## 架构

判断层（轻量配置：非思考 + 低温度）轮流询问每个角色是否被叫 → 命中角色用主模型（人格 + 状态注入）生成台词。判断与生成分离，保证判断速度与生成质量。
